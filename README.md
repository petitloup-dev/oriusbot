## Why OriusBot

**One bot instead of six.** OriusBot protects a server from scams and raids, moderates it, keeps the community active and gives the staff a real workspace — configured from a web panel instead of configuration files.

- 🛡️ **Protection from minute one** — anti-spam, anti-raid, link, image and file scanning are on as soon as the bot joins. Everything else only switches on when you ask.
- 🔒 **Private by design** — all analysis runs on our own infrastructure. No message is sent to a third-party service, and no data is ever sold.
- 🌍 **Four languages** — the bot, the web panel and the documentation exist in English, French, Spanish and Portuguese, chosen server by server.
- 🧭 **Explained, not just configurable** — `/setup` walks through every setting and says what it does.

## Features

### 🛡️ Security
| | |
|---|---|
| **OriusLens** | Recognises scam images (fake Nitro, fake giveaways, trapped QR codes), even cropped or recoloured |
| **OriusGuard** | File antivirus: disguised executables, Discord token grabbers, crypto clippers |
| **OriusMod** | Catches insults and harassment in four languages, and learns from your corrections |
| **Anti-raid & anti-nuke** | Detects waves of new accounts and destructive scripts — bots included — and restores what an attacker deleted |
| **Anti-VPN captcha** | Filters throwaway accounts at the door without scaring off real members |
| **Shared reputation** | A threat blocked on one server protects every server in the network |

→ [How Discord scams work, and what stops them](https://oriusbot.com/en/guides/arnaque-discord-nitro-phishing) · [Protect a server from raids](https://oriusbot.com/en/guides/proteger-serveur-discord-raid)

### ⚖️ Moderation
Warnings with automatic escalation, timeouts and bans, cross-server bans, emergency lockdown, action undo, persistent audit logs, word filter and permission audit. Every command can be enabled, disabled or restricted to a role from the panel.

### 🎉 Engagement
Text and voice XP with custom level cards and level roles, economy and role shop, mini-games, giveaways, birthdays, starboard, question of the day, temporary voice channels, welcome images, role menus, server rules with an "I accept" button.

### 🎫 Support & alerts
Tickets with themes, claiming and transcripts, an assistant that answers recurring questions, suggestions, anonymous confessions — plus Twitch, YouTube and RSS alerts.

### 👥 Staff CRM
Recruit moderators with public application forms, track activity, plan shifts, manage absences and trial periods. Moderators get their own space without being server administrators.

→ [Recruit and manage a staff team](https://oriusbot.com/en/guides/crm-staff-discord-recrutement)

### 🟣 Twitch (open beta)
A Twitch chat bot linked to your Discord server: custom commands, chat moderation, bridged chats and shared Twitch ↔ Discord XP.

## Getting started

1. **[Add the bot](https://discord.com/oauth2/authorize?client_id=1335945035564449803&permissions=2253434048212479&scope=bot+applications.commands)** — basic protection turns on by itself.
2. Run **`/setup`** in your server — a step-by-step assistant explains every setting.
3. Fine-tune the rest in the **[web panel](https://oriusbot.com)**.

Full reference of every command and panel screen: **[oriusbot.com/en/wiki](https://oriusbot.com/en/wiki)**.
